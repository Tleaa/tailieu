# Animated Worlds | tailieu

A responsive mini website introducing four popular animated TV shows: Steven Universe, Adventure Time, Masha and the Bear, and The Powerpuff Girls.

- Open `index.html` to view the website.
- Features: responsive layout, show search, genre filters, and expandable information cards.
- To publish with GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
